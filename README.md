В этом репозитории находятся домашние задания по введению в специальность.


В папке dz_1 находится домашнее задание 1, состоящее из четырех задач (калькулятор с 4 if, калькулятор с 4 функциями, калькулятор с использованием 1 функции, калькулятор "расчет нормы веса" с помощью классов).

В папке dz_2 находится домашнее задание 2 (игра с 5 уровнями на использование различных методов).

В папке dz_3 находится домашнее задание 3 (игра - лабиринт. игрок ходит по полю 5×7, собирает предметы и сражается с монстрами. цель - найти ключ, открыть сундук, узнать код и выйти через дверь. монстры отнимают hp (меньше, если есть оружие и зачарование), аптечки лечат, золото собирается для счёта. расположение объектов каждый раз случайное).
